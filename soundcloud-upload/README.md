# soundcloud-upload

Простой скрипт на Python для загрузки треков на SoundCloud через автоматизацию браузера (Playwright), без использования официального API (доступ к которому SoundCloud выдаёт только по ручному одобрению — можно ждать неделями).

## ⚠️ Важно

Это **не официальный инструмент** и не использует SoundCloud API. Скрипт управляет настоящим браузером и делает то же самое, что сделал бы ты сам руками: открывает страницу загрузки, подставляет файл, заполняет поля и нажимает «Save».

- Логин и пароль скрипт **не хранит и не запрашивает** — ты логинишься сам, вручную, в открывшемся окне браузера один раз, дальше используется сохранённая сессия.
- Так как это автоматизация UI, а не API, при изменении вёрстки сайта SoundCloud что-то может сломаться. Скрипт написан так, чтобы в таком случае не падать молча, а останавливаться и просить доделать шаг вручную.
- Используй на свой страх и риск и только для своего аккаунта — это не предназначено для массовой/коммерческой автоматизации.

## Требования

- Python 3.8+
- [Playwright](https://playwright.dev/python/)
- (опционально) PyInstaller — если хочешь собрать `.exe`

## Установка

```bash
git clone https://github.com/<твой-юзернейм>/soundcloud-upload.git
cd soundcloud-upload
pip install playwright
python -m playwright install chromium
```

> **Windows/PowerShell:** если команда `playwright` пишет `не распознано как имя командлета` — это значит, что exe-шники из папки Python `Scripts` не попали в PATH. Обходной путь: везде вызывать через `python -m`, например `python -m playwright install chromium` вместо `playwright install chromium`. Та же история с `pyinstaller` (см. ниже).

## Использование

### 1. Логин (один раз)

```bash
python soundcloud_upload.py --login
```

Откроется окно браузера — залогинься в SoundCloud **напрямую по email и паролю** (не через кнопку «Войти через Google» — см. раздел про Google ниже). Затем вернись в терминал и нажми Enter. Сессия сохранится локально в папке `sc_browser_profile/` (она в `.gitignore`, наружу не уходит).

**Не закрывай окно браузера вручную** до того, как нажмёшь Enter в консоли — иначе логин может не сохраниться, а скрипт выведет предупреждение вместо ошибки (это ожидаемо и не страшно, просто повтори `--login`).

### 2. Загрузка трека

```bash
python soundcloud_upload.py "path/to/track.mp3" --title "Track name"
```

### Доступные флаги

| Флаг              | Описание                                      |
|--------------------|------------------------------------------------|
| `--title`          | название трека (обязательно)                  |
| `--private`         | сделать трек приватным (по умолчанию публичный)|
| `--tags "a b c"`    | теги через пробел                              |
| `--description "…"` | описание трека                                 |
| `--no-close`        | не закрывать браузер сразу после загрузки      |
| `--login`           | только залогиниться и сохранить сессию         |

## Сборка .exe (опционально)

Если хочешь запускать без установленного Python:

```bash
pip install pyinstaller
python -m PyInstaller soundcloud_upload.spec
```

Готовый файл появится в `dist/soundcloud_upload.exe`. Флаги (`--title`, `--private` и т.д.) работают так же, как у `.py`-версии:

```bash
dist\soundcloud_upload.exe "путь\к\треку.mp3" --title "Название"
```

Важно: Chromium для Playwright по-прежнему нужно ставить отдельно (`python -m playwright install chromium`) — PyInstaller не умеет упаковывать его внутрь `.exe`, это ограничение самого Playwright, а не сборщика.

Если захочешь свою иконку — положи `icon.ico` рядом со `.spec`-файлом и раскомментируй строку `icon='icon.ico'` в конце `soundcloud_upload.spec`.

## Как это работает

Скрипт запускает Chromium с постоянным профилем (где хранится твоя сессия), открывает `soundcloud.com/upload`, подставляет файл в поле загрузки, дожидается формы редактирования трека и заполняет название/теги/описание/приватность, затем нажимает «Save».

Если на каком-то шаге автоматический поиск нужного элемента страницы не сработал, скрипт остановится и попросит тебя выполнить этот шаг вручную в открытом окне, после чего продолжит выполнение.

## Troubleshooting

**`playwright`/`pyinstaller` : Имя не распознано как имя командлета...**
PATH не видит exe-шники Python-пакетов. Вызывай через `python -m`, например `python -m playwright install chromium` или `python -m PyInstaller soundcloud_upload.spec`.

**Google: «Не удалось войти в аккаунт» / «этот браузер или приложение небезопасны»**
Это защита Google от автоматизированных браузеров, срабатывает при попытке войти через кнопку «Войти через Google» внутри Playwright-браузера. SoundCloud тут ни при чём. Решение: залогинься в SoundCloud напрямую по email и паролю (не через Google). Если аккаунт создавался только через Google — сначала зайди в обычном браузере в настройки SoundCloud и задай пароль для аккаунта.

**Форма логина открылась пустой/белой**
Баг рендера в свежем профиле браузера. Обнови страницу (F5) прямо в открывшемся окне и попробуй снова, не закрывая окно.

**`TargetClosedError` / `Target page, context or browser has been closed`**
Окно браузера было закрыто вручную раньше, чем нажали Enter в консоли. Не страшно — просто повтори `--login`, дождись реального входа в аккаунт (виден профиль/аватар) и только потом жми Enter, дав скрипту самому закрыть браузер.
